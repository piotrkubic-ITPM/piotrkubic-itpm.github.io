HOW TO PUBLISH WITH GITHUB PAGES

1. Create a public GitHub repository named YOURUSERNAME.github.io.
2. Upload the four files from this folder to the root of that repository (index.html, portrait.jpg, contact.vcf, Piotr_Kubic_CV.pdf).
3. Go to Settings > Pages > Build and deployment, choose Deploy from a branch, main and /(root), then Save.
4. Visit https://YOURUSERNAME.github.io/ after deployment.
5. Only after the address works, update the QR code and PDF business card to point to this URL.

Note: Public GitHub Pages means your phone number, email address, photograph and CV are publicly accessible. LinkedIn may require login.
